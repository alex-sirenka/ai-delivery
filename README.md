# AI Delivery Manager Academy

Learn AI delivery management in short daily sessions. Each time you press **Start**, you get 1–2 new topics (5 minutes maximum) plus a short recap of an earlier topic. There are 129 topics in 16 chapters, which takes about 65 sessions.

**Live app:** https://alex-sirenka.github.io/aidm-academy/

## Features
- 1–2 new topics per Start, each with meaning, example, best practices, a common mistake and a question to ask on your project
- Progress by chapter, streak, session history, bookmarks and a searchable library
- Daily reminder: downloads a recurring calendar event (.ics) for Outlook, Google Calendar or your phone
- Installable on your phone (Add to Home Screen) and works offline
- Progress is stored in your browser; you can export and import it in Settings

## Files
| File | Purpose |
